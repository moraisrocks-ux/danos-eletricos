# Danos Elétricos - Sistema de Relatórios

Sistema para gerar e exportar relatórios de danos elétricos em formato ZIP.

## 🚀 Recursos

- ✅ Análise de danos elétricos
- ✅ Geração de relatórios em PDF/HTML
- ✅ Exportação em ZIP
- ✅ Dashboard de visualização
- ✅ API REST

## 📦 Instalação

```bash
pip install -r requirements.txt
```

## 🏃 Como Usar

```bash
python main.py
```
